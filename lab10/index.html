5. Design Reflection

Lab 5's node-link graph was extended with voice interaction. The task now supports real-time manipulation of the visualization through spoken guidance. Users can filter the graph by district or station type, highlight an individual station, and reset the view without touching the screen or using a mouse. This interaction is especially appropriate when the visualization is shown on a large display or larger device because users can control the graph from a short distance while still receiving immediate feedback about what the system heard and which action it applied. This can make exploration more efficient and intuitive in presentation settings. One limitation is that the voice recognition module is not always active. The user must return to the top of the page and press the voice-control button before each command, which requires scrolling back and forth when examining lower parts of the page. A persistent or floating activation control would work better, particularly on larger displays.
