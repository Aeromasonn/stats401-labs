Urban Transit Network

Each symbol represents one station. Symbol size shows daily_passengers, symbol color shows district, line width shows travel_time_min, and line color shows route_type. Node shape shows station_type: a circle is Local, a triangle is Transfer, and a square is Terminal.

Node-Link Design Description

Larger stations show heavier passenger use, so busy places stand out quickly. District colors help group stations by area. Plain circles, triangles, and squares distinguish local, transfer, and terminal stations alongside showing the district color. Wider lines make long direct trips easy to notice, while line colors separate Metro, Express, and Shuttle routes. Dragging makes crowded areas easier to read, and hovering highlights a station's direct connections and shows its details.

Adjacency Matrix

Rows and columns represent stations. Colored cells show direct routes, and darker cells represent longer travel_time_min values.

Matrix Design Description

Each row and column is a station in ID order. This makes the long station-to-station chain appear near the diagonal, while cross-links stand away from it. Blue cells show direct connections, and darker cells show longer trips. I kept the matrix simple so the 50-by-50 grid stays readable: it is useful for checking connections and travel time, but it does not show district or station type as clearly as the graph.

Network Questions and Findings

  • 1. Which stations appear central? Partially — both views. Link count in the graph and non-empty cells in a matrix row or column indicate degree, but neither view calculates a formal centrality measure. There is no dominant hub: Stations 4, 7, 10, 13, 16, 18, 21, 23, 25, 29, 31, 33, 34, and 38 have degree three, the maximum.
  • 2. Which districts connect most strongly? Not easily — node-link if one has to be identified. District colors make individual memberships visible, but the ID-ordered matrix does not form district blocks. The view therefore suggests mixed cross-district connectivity rather than a visually obvious strongest district pair; finding one would require counting connections.
  • 3. Where are transfer or terminal stations located in the topology? Well — node-link. Triangles show transfers and squares show terminals, so their positions can be seen without hovering. Both types are spread along the main chain rather than forming one central group; for example, Stations 4 and 7 are terminals, while Station 23 is a transfer station.
  • 4. Which stations have the highest passenger volume? Well — node-link. Symbol size makes passenger volume immediately visible. Stations 46–50 are the five largest symbols, so they are the highest-volume stations. Specific values need referring to the csv file.
  • 5. Which are the longest direct routes? Well — both views. The widest edge and darkest matrix cells flag long direct routes. Station 7–31 is longest as it appear to be the thickest minutes, then 18–34 and 29–50 appearing at similarly width levels.
  • 6. Do route types have a spatial pattern? Partially — node-link. Edge color separates route types, but the force layout's positions are not geography. Colors are interspersed along the main chain and cross-links, so no type has a clear spatial concentration.
